## What Is Apex Box Counter?

Apex Box Counter provides a dedicated browser interface for keeping an accurate tally of Apex boxes. It is useful whenever a clearly visible count is more practical than writing down totals manually or using a broader-purpose application.

The tool is intentionally focused on one task. Open it in a supported browser, count boxes as you go, and use the displayed total to track progress. Because it is delivered as an HTML application, it can be opened quickly without installing a separate desktop program.

To use the application:

1. Launch Apex Box Counter.
2. If required, return the counter to its initial value.
3. Increment the displayed count for every Apex box.
